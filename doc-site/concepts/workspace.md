# 工作区

**工作区**是当前 Agent 的文件和会话边界，可以是浏览器 IndexedDB 中固定的聊天工作区，也可以是你授权访问的本地文件夹。所有相对路径、预览和 Agent 读写都以当前工作区为根。

## 为什么要有工作区

浏览器默认不能随便读写你的磁盘。你通过系统对话框选中文件夹并授权后，Agent 才能在这个范围内工作——这是「本地优先」的起点。

如果不需要已有文件，可从欢迎页直接进入聊天工作区，无需目录权限。它会长期复用，直到你在工作区管理中清空或删除浏览器站点数据。

## 你可以做什么

- 在欢迎页直接进入聊天工作区，或打开新文件夹
- 从最近列表恢复（可能仍需再次点允许）  
- 在设置里管理已登记的工作区相关选项  

![欢迎页：打开本地工作区](/images/concept-workspace-open.png)

## 边界在哪里

| 可以 | 不可以 |
|------|--------|
| 读写工作区内部文件与子目录 | 访问工作区外的路径 |
| 在 `.cottage/` 存会话与配置 | 用 `../` 逃逸到上级目录 |

## 和「项目」的关系

一个 Git 仓库、一个文档资料夹、一个客户交付目录，都可以各自作为一个工作区。换文件夹 = 换一套会话与工作区配置（域名级设置仍可能共用，见 [两层配置](./storage-layers)）。
