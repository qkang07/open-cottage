# 暂存审阅与审批

这两个机制都是为了：**结果可核对、危险可叫停**。

## 暂存审阅（Staging Review）

默认常开。Agent 的写操作可以先进入「暂存」，你看过 diff 再决定：

- **应用** → 真正写入磁盘  
- **丢弃** → 不要这次改动  

适合：不熟悉仓库、第一次用、批量改文件时。

![三个新文件的逐项差异审阅界面](/images/concept-staging.png)

## 审批闸门（Policy）

按风险级别拦截工具。默认对**破坏性**操作（如删除）弹出允许 / 拒绝。

拒绝后，Agent 会收到「被策略阻止」，一般会换做法或向你确认。

## 两者差别（一句话）

| | 审的是什么 | 时机 |
|--|------------|------|
| 审批 | 「能不能执行这个动作」 | 调用前 |
| 暂存 | 「执行结果要不要留下」 | 写入前/落盘前 |
