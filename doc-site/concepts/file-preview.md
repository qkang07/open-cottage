# 文件预览

**预览**是点开文件后出现的中间区域：查看（部分类型还可编辑），用来**验收 Agent 的交付物**。未打开文件时，主界面以文件侧栏与聊天为主。

## 支持哪些类型（常见）

| 类型 | 表现 |
|------|------|
| Markdown / 纯文本 / 代码 | 渲染或文本编辑 |
| HTML | 预览；图表、演示页常是这种 |
| 图片 / 视频 | 媒体预览 |
| Word / PPT / 表格 | 办公预览（由对应能力读写生成） |

具体以当前版本界面为准。

![HTML 柱状图文件的预览界面](/images/concept-preview-kinds.png)

## 预览在工作流里的位置

```
对话里交代任务 → Agent 写入文件
       ↓
左侧文件树更新 → 点开文件在预览区核对
       ↓
不满意 → 继续对话修改；满意 → 结束（或应用暂存）
```

没有预览，就只剩「模型说完成了」——这正是产品要避免的。

## 和聊天的联动

- 预览中选中内容，可 **加入对话**（若该类型支持）  
- 输入框用 `@` 引用文件，等于把路径钉进上下文  
- HTML 图表可用「新窗口打开」全屏看  

见操作文：[预览、引用与附件](/guide/preview)

## 注意

- 二进制办公文件请用办公能力生成/修改，再预览；不要当纯文本硬打开乱码后强行保存  
- 部分 HTML 图表依赖联网脚本，离线可能空白
