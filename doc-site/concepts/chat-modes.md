# 对话、计划与会话

## 对话模式（Chat）

默认协作方式：你发一句，Agent 调工具、再回复。适合问答、小改、边试边调。

跟做：[和 Agent 对话](/guide/chat)

## 计划模式

先产出一份结构化计划（目标、任务、风险、验收），**你批准后再执行**。适合步骤多、怕跑偏的任务。

跟做：[计划模式](/guide/spec)

| | 对话 | 计划 |
|--|------|------|
| 何时 | 小而清晰 | 大而需对齐 |
| 节奏 | 即时工具循环 | 先批后做 |
| 验收 | 靠你边看边说 | 计划里先写清 |

## 会话（Session）

右侧可以有多条会话，互不干扰：

- 每个会话有自己的消息历史  
- 保存在工作区 `.cottage/` 下  
- 换文件夹不会带走另一个工作区的会话
