# 能力包

**能力包（Capability Pack）** 是一组可开关的「本事」：工具 + 领域提示词（有时还有技能）。  
基础能力始终可用；领域能力是否启用由当前保存的配置决定，可在界面中按任务调整。

## 为什么要开关

不需要的能力可以关闭，减少可调用工具并让边界更清晰；系统不会因一次提示词静默改写你的选择。

## 你在界面上怎么操作

1. 聊天输入区上方打开 **模型与能力**  
2. 打开本次需要的包  
3. 或到 **设置 → 能力配置** 查看说明  

![设置 → 能力配置 → 内置能力](/images/concept-packs-toggle.png)

## 内置包速览

| 包 | 什么时候开 |
|----|------------|
| 基础 | 不用开，始终可用 |
| 办公文档 | Word / PPT / 表格 |
| 代码改造 | 改仓库代码 |
| PDF / 图表 / 深度研究 / 网页自动化 | 见名称；网页自动化还要 Cottage Service |

完整跟做：[按场景操作](/guide/use-office) · 清单：[能力说明](/packs/)

## 和「工具」的关系

打开一个包 ≈ 允许 Agent 使用该包登记的那一组工具。  
配置里常用「启用的工具名列表」来表达；对用户而言记住**开哪个包**即可。

## 外部包与 MCP

- 外部 Pack：安装到 `.cottage/packs/`，可带自己的工具与说明  
- MCP：在设置里接远程工具服务器（默认关）  

见 [安装外部能力](/packs/external)。

## 常见误解

| 误解 | 实际情况 |
|------|----------|
| 「装好就能写 PPT」 | 还要打开办公能力包 |
| 「能力包 = 插件市场 App」 | 更像「工具箱抽屉」，装在本工作区/本产品内 |
| 「关包会删我的文件」 | 只是下次对话不再注入那些工具 |
