# 「模型与能力」面板

聊天输入区上方的面板，是日常最高频的控制台之一。

## 通常能做什么

- 切换当前模型 / 预设  
- 打开或关闭能力包  
- （视版本）看到与当前任务相关的能力建议  

![聊天输入区上方展开的模型与能力面板](/images/concept-model-capability-panel.png)

## 和「设置」的分工

| | 模型与能力面板 | 设置抽屉 |
|--|----------------|----------|
| 节奏 | 对话中途快速切 | 首次配置、细项 |
| 典型 | 换模型、开办公包 | Key、Service、治理 |

Key、分层保存、Cottage Service 连接等仍在 **设置** 里完成。
