# @ 引用与附件

## @ 引用文件

在输入框输入 `@`，从工作区挑选文件，把路径钉进本轮消息。  
作用：减少 Agent 盲目搜索，明确「就改这个 / 就基于这个」。

![在输入框中输入 @ 后显示文件候选](/images/at-mention.jpeg)

## 附件

可把图片等材料附在消息上（需模型支持视觉时更有用）。  
附件通常落到工作区 `.cottage/attachments/`，仍属本地数据。

## 预览「加入对话」

在预览区选中一段文字，若提供「加入对话」，等价于把摘录带进上下文，适合精确指出某一段。
