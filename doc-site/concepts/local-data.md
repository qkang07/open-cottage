# 数据在本地

Open Cottage 的核心承诺之一：**项目相关数据默认落在你自己的文件夹里**，而不是上传到某个「Cottage 云端」。

## 落在工作区里的东西

打开工作区后，目录下会出现（或逐步写入）`.cottage/`，常见内容：

| 内容 | 作用 |
|------|------|
| `config.json` 等设置文件 | 本工作区在设置里改过的选项（**不含** API Key） |
| 会话文件 | 聊天历史，换电脑带走文件夹还能接着看 |
| `history/v2/` | 启用版本历史 Beta 后保存的版本数据 |
| `attachments/` | 聊天附件 |
| `packs/` | 安装的外部能力包 |
| 其它运行时数据 | 如 trace 等 |

<Callout kind="tip">`.cottage/` 是工作区内部数据目录，应用文件树可能隐藏它。备份或迁移时请在系统文件管理器中确认整个目录已一并复制。</Callout>

## 不会进 `.cottage/` 的东西

最重要的是：**各厂商 API Key**。  
Key 存在浏览器的 IndexedDB 里，详见 [模型、预设与 API Key](./models-and-keys)。

## 备份与迁移

想换电脑或做备份时：

1. 拷贝整个工作区文件夹（含 `.cottage/`）  
2. 在新环境打开同一目录  
3. 重新授权文件夹访问  
4. **重新填写 API Key**（或改用你自己的代理）  

会话、工作区配置可以跟着走；浏览器里的密钥不会跟着文件夹走。

## 「本地」不等于「不上网」

本地优先指的是**你的文件与会话默认在本地**。  
Agent 仍可能：

- 调用云端 LLM API（你配置的提供商）  
- 按你的要求搜索 / 打开网页  
- 连接本机 Cottage Service  

这些都是你主动配置或指令触发的，不是把工作区默默同步到云盘。
