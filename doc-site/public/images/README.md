## 截图原则

- 使用真实产品界面，不用生成图或不相关界面冒充。
- 截图前清除 API Key、真实姓名、邮箱、路径等敏感信息。
- 当前公开版没有可复现界面，或能力依赖未连接服务时，正文应直接说明状态，不保留“待补截图”占位。
- 更新截图后，同时检查 Markdown 引用与实际文件名是否一致。

示例：

```md
![主界面](/images/main-ui.png)
```
