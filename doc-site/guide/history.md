# 版本历史 Beta

<StoryLead label="版本历史 Beta">

版本历史 为当前工作区保存可管理的版本记录，用于在改动后查看差异、恢复单个文件或回到较早的工作区状态。它默认关闭，只有明确启用后才开始记录。

</StoryLead>

## 为什么叫 Beta

版本历史还是一个试验中的功能：默认关闭，只有你明确为某个工作区启用后才开始记录，做法之后也仍可能调整。特别重要的内容，请照常自行备份。

## 先为这个工作区打开它

1. 打开一个工作区。
2. 进入 **设置 → 版本历史 Beta**。
3. 开启版本历史，并按需要设置文件与工作区总容量。

记录保存在当前工作区的 `.cottage/history/v2/`，不会上传。旧历史目录不会被读取、迁移或删除。

## 当你需要回看或恢复

启用后，文件区工具栏会显示 **版本历史**；右键某个文件也可选择 **查看此文件的历史**。你可以查看时间线、变更文件和差异，预览文本或图片版本，并恢复单个文件或选定的工作区树。

<StoryBeat title="恢复保护机制">

恢复前应用会先建立保护版本。超过容量限制或无法完整恢复时，会明确提示；你仍能停下来决定是否继续。

</StoryBeat>

## 容量与备份

- 单文件和工作区历史池都有独立上限；超限时会跳过不可记录内容或清理最旧版本。
- 文本和二进制文件都按原始字节保存。
- 备份工作区时，连同 `.cottage/` 一起复制；是否保留历史取决于你是否已启用它。
