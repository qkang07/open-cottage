# 从一个文件夹开始

## Open Cottage 是什么？

Open Cottage 是一个浏览器里的本地文件夹 Agent。它利用 Chrome 或 Edge 的目录访问权限，让你选择一个本地文件夹作为工作区；配置模型后，便可以在其中完成与其他 Agent 工具相同的核心工作：读写文件、调用工具、生成内容和处理任务。

不需要额外安装桌面客户端，也不需要先搭建一套复杂的本地运行环境。浏览器负责界面和目录授权，本地文件夹提供工作区边界，模型与能力包负责完成任务——这组简单组合就是 Open Cottage 的基础。

## 最小使用流程

1. 在 Chrome 或 Edge 中打开官方 Demo，或运行自行部署的实例。
2. 选择一个本地文件夹，并授权浏览器访问。
3. 配置模型；需要时再开启相应能力。
4. 用自然语言说明任务，结果直接写入该文件夹。

例如，选择一个已有项目目录，配置模型后，就可以让 Agent 阅读文件、修改代码或生成新文件；它不要求你把项目迁移到某个专用平台。

## 核心特点

### 浏览器即可运行

Open Cottage 是纯前端应用。官方 Demo 可直接体验；高级用法、定制或配套服务需求下，可获取开源代码并在自己的环境中部署。

<ProjectLinks />

### 本地文件夹就是工作区

你选择的目录是当前任务的文件范围。已有项目、文档资料或其他本地目录无需迁移，Agent 直接在原有位置工作。

### 能力按需组合

模型与能力包按任务启用。办公文档、代码改造、调研、网页处理、PDF 与图表等能力都在这里提供，但不构成开始使用的前提；需要时从顶部“按场景”进入对应说明即可。
