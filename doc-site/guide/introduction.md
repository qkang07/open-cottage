# 直接开始，或从一个文件夹开始

## Open Cottage 是什么？

Open Cottage 是一个浏览器里的 Agent。你可以直接进入保存在 IndexedDB 的聊天工作区，也可以利用 Chrome 或 Edge 的目录访问权限，把已有本地文件夹作为工作区；配置模型后即可读写文件、调用工具和生成内容。

不需要额外安装桌面客户端，也不需要先搭建复杂的本地运行环境。浏览器负责界面和虚拟工作区存储；需要处理已有资料时，再授权本地文件夹作为工作区边界。

## 最小使用流程

1. 在 Chrome 或 Edge 中打开官方 Demo，或运行自行部署的实例。
2. 选择“直接开始聊天”，或选择一个本地文件夹并授权浏览器访问。
3. 配置模型；需要时再开启相应能力。
4. 用自然语言说明任务，结果写入当前虚拟工作区或已授权文件夹。

例如，选择一个已有项目目录，配置模型后，就可以让 Agent 阅读文件、修改代码或生成新文件；它不要求你把项目迁移到某个专用平台。

## 核心特点

### 浏览器即可运行

Open Cottage 是纯前端应用。官方 Demo 可直接体验；高级用法、定制或配套服务需求下，可获取开源代码并在自己的环境中部署。

<ProjectLinks />

### 本地文件夹就是工作区

你选择的目录是当前任务的文件范围。已有项目、文档资料或其他本地目录无需迁移，Agent 直接在原有位置工作。

### 无需文件夹的聊天工作区

欢迎页的“直接开始聊天”会创建并持续复用一个虚拟工作区。会话、配置和生成文件保存在当前站点的 IndexedDB 中，左下角显示其逻辑数据大小；可在工作区管理中确认后清空。清除浏览器站点数据也会删除这些内容。

### 能力按需组合

模型与能力包按任务启用。办公文档、代码改造、调研、网页处理、PDF 与图表等能力都在这里提供，但不构成开始使用的前提；需要时从顶部“按场景”进入对应说明即可。
