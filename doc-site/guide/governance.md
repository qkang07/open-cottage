# 审阅与批准改动

<StoryLead label="写入与确认">

Open Cottage 默认让你在写入前查看改动：可先审阅 diff 的操作进入暂存区，删除等危险操作会暂停并等待你的允许或拒绝。

</StoryLead>

## 先用暂存把改动摊开

写操作可以先进入暂存区，而不是立刻落盘。出现暂存提示或横幅时，打开变更列表，按文件看 diff，再选择 **应用** 或 **丢弃**；界面提供按文件操作时，也可以只接受其中一部分。

![三个新文件的逐项差异审阅界面](/images/staging-review.png)

暂存审阅在 **设置 → 能力配置 → 治理策略 → 暂存审阅** 中开关。第一次处理陌生目录时，建议保持开启。

## 危险动作会停下来问你

删除等破坏性操作默认会弹出 **允许 / 拒绝**。先看它要删什么、为什么要删；确认无误再允许。拒绝后，模型会收到策略阻止信息，通常会换一种做法。

![Agent 询问用户并等待审批](/images/policy-approval.png)

<StoryBeat title="建议的确认方式">

批量删除、清空目录时，先让它只列清单；网页自动化涉及登录、提交或付费时，盯住每一步。你不是在打断工作，而是在决定哪些结果值得落下。

</StoryBeat>
