# 预览、引用与附件

<StoryLead label="如何验收结果">

预览用于确认生成或修改的文件是否位于指定路径、内容是否正确、版式是否可读。你还可以用 `@` 或预览区选中的内容，把现有材料带入下一轮对话。

</StoryLead>

## 用预览确认交付物

1. 在左侧文件树点开 Agent 生成或修改的文件。
2. 在预览区查看内容与版式；没有预览时会自动展开。
3. HTML 图表或演示可用「新窗口打开」全屏查看。

![Markdown 表格与待办清单预览](/images/preview-pane.png)

<Callout kind="warn">
Word / Excel / PPT / PDF 请让它用对应能力工具处理，不要把二进制文件当纯文本直接读写。
</Callout>

## 少重复描述，多引用材料

在输入框输入 `@`，选择文件，就能把它钉到本轮对话。遇到预览区支持选中文本并加入对话时，也可以直接带走关键段落，继续说“基于这里再改一版”。

![输入 @ 后显示文件候选](/images/at-mention.jpeg)

## 最后看四件事

- [ ] 路径是否在你指定的目录。
- [ ] diff 是否只改了你想改的部分。
- [ ] 文档、幻灯片或图表的版式是否可读。
- [ ] 调研类交付物是否带来源并已落盘。
