# 设置界面

打开右上角 **设置**（或「AI 与 API 设置」）。这里负责长期配置；聊天输入区上方的 **模型与能力** 面板则适合对当前对话快速切换。

![设置抽屉：顶部页签一览](/images/settings-tabs-overview.png)

## 页签一览

| 页签 | 用来做什么 |
|------|------------|
| **模型配置** | 添加/编辑模型预设、填 API Key、设默认模型 |
| **能力配置** | 基础工具、联网、MCP、技能、脚本、治理；内置/第三方能力包 |
| **工作区管理** | 管理已打开的工作区文件夹 |
| **版本历史 Beta** | 为当前工作区明确启用版本记录、设置容量并管理版本 |
| **Cottage Service** | 连接本机伴随服务、选择走哪些能力 |
| **图片** | 配置图片附件的启用状态、存储方式和大小限制 |

## 模型配置

1. 选择提供商；自定义端点时填写 Base URL。
2. 填入 API Key，选择或手动填写模型。
3. 保存并按需设为新聊天默认模型。

Key 只保存在浏览器本地，不会写进工作区文件。提供商、代理与模型列表的说明见 [模型提供商与 Key](./models-and-keys)。

![模型配置页：服务商与模型入口](/images/settings-model-presets.png)

## 能力配置

这里分为基础能力、内置能力与第三方能力：

- **基础能力**：文件、联网搜索、MCP、技能、脚本超时和治理策略。
- **内置能力**：办公、编码、PDF、图表、图片生成、深度研究、网页自动化等，开启后 Agent 才会带上对应工具。
- **第三方能力**：打开工作区后，可导入 `manifest.json`、启用或移除已安装包。

治理策略决定哪些风险等级必须先确认；暂存审阅可以先看 diff，再决定是否写入工作区。

![能力配置 → 治理策略（审批 + 暂存审阅）](/images/settings-governance.png)

## 工作区与版本历史

工作区管理用于打开、切换或清理浏览器记住的工作区入口。换文件夹不会清除域名级模型预设；工作区自己的能力开关会随文件夹保存。

版本历史 Beta 默认按工作区关闭。启用后会把版本数据保存在当前工作区 `.cottage/history/v2/`，并可设置单文件与工作区总容量。详见 [版本历史 Beta](./history)。

## Cottage Service 与图片

- **Cottage Service**：连接后可按需让搜索、抓取、HTTP 代理和网页自动化走本机伴随服务。
- **图片**：控制粘贴、拖拽和上传；可要求当前模型支持视觉能力，并设置附件存储与大小限制。

![Cottage Service 页：连接状态与选项](/images/settings-cottage-service.png)

图片生成的厂商、模型、API Key 和默认尺寸在 **模型配置** 中设置；启用聊天区的图片生成能力后，结果会保存到工作区。

## 保存范围与生效时机

| 你想做什么 | 去哪 |
|------|------|
| 换默认模型、填 Key | 设置 → **模型配置** |
| 细调治理、MCP、联网路由 | 设置 → **能力配置** |
| 当前对话临时开办公/编码 | 聊天区 **模型与能力** |
| 管理当前工作区的版本 | 设置 → **版本历史 Beta** |
| 接上搜索/自动化后端 | 设置 → **Cottage Service** |

多数开关保存后，正在进行的对话可能需要新开一轮或等待 Agent 重新挂载才完全生效；以界面提示为准。
