# 认识主界面

<StoryLead label="界面分工">

打开工作区后，默认是左侧文件区与右侧聊天区。点开文件、出现待审阅改动或进入资源管理器时，中间会出现预览区，用于查看内容和确认结果。

</StoryLead>

![打开工作区后的主界面](/images/main-ui.png)

![工作界面布局](/images/page-structure.jpeg)

## 左边先看材料

文件区是工作区的入口。你可以浏览目录、新建或重命名文件；点开一个文件，它会在中间预览。刚才让 Agent 写入的 `notes/quickstart.md`，也应该从这里找到。

## 中间留给确认

预览区按需出现：文本、Markdown、图片、HTML、办公文档，以及 Agent 生成的 PPT、图表和报告都在这里看。部分内容可选中后 **加入对话**，让你不用重新描述那一段材料。

<StoryBeat title="预览用于验收">

真正的验收发生在预览里：看文件是否落在指定路径、内容是否完整、版式是否可读。出现待审阅的暂存改动时，这里也会成为你比较 diff 的地方。

</StoryBeat>

## 右边用来继续交代

右侧是对话与多会话切换的位置。输入框上方可以选择 **模型与能力**，并切换 **对话 / 计划** 模式；消息流里会显示工具调用过程，顶部可能出现审批或暂存审阅条。

## 顶栏处理环境本身

顶栏的 **设置** 管理模型、能力、Service 与治理；主题、语言和更换或离开工作区也在这里。它们不是每次任务都要动的地方，先让第一个任务跑起来即可。
