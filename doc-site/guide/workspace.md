# 工作区与数据在哪

<StoryLead label="工作区边界">

工作区是你授权给 Agent 的本地文件夹。Agent 只在这个边界内读写文件；会话、附件与工作区配置保存在其中的 `.cottage/` 目录，便于随项目一起备份。

</StoryLead>

## 文件夹就是边界

Agent 只能在这个目录内按相对路径操作，不能随意触及电脑上的其它位置。开始一个任务时，先确认选的是正确项目或资料目录，比之后补救更省心。

## `.cottage/` 让对话接得下去

| 内容 | 用途 |
|------|------|
| 配置 | 模型选择、打开了哪些能力等（**不含** API Key） |
| 会话 | 聊天记录 |
| 附件 | 聊天附件 |
| 外部能力包 | 安装到 packs 下的扩展 |

把整个项目文件夹拷走（含 `.cottage/`），在另一台电脑打开同一目录，上下文大多可以延续。API Key 仍需要在新浏览器里重新配置。

<StoryBeat title="备份注意事项">

`.cottage/` 可能不会显示在应用文件树中。用系统文件管理器复制整个工作区，才能把会话、附件与已启用的工作区配置一起保住。

</StoryBeat>

## 什么时候需要额外备份

想保留对话与配置，就备份整个工作区；Key 保存在浏览器里，换机器后重新填写，或改由代理侧保存。想把一次重要修改也留一条可恢复的记录，可以再启用版本历史。

<NextReading to="./history" title="给重要改动留一条可恢复的轨迹">

版本历史默认关闭；需要时，你可以明确为当前工作区打开它。

</NextReading>
