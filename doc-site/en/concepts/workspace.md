# Workspaces

A workspace is the Agent's file and conversation boundary. The fixed chat workspace lives in this site's IndexedDB and needs no folder permission. An authorized local folder keeps source material, results, conversations, attachments, settings, and optional external packs under `.cottage/`.

Use the chat workspace to start immediately, and choose a folder when a project, client delivery, or material collection needs its own context. Switching workspaces does not delete either one. Clearing browser site data does delete the virtual workspace.
