# Cottage Service

Cottage Service is an optional companion service for enhanced search and fetching, a headless browser, webpage screenshots, and web automation. The main Agent and local-folder workspace continue to run in the browser.

Connect it from **Settings → Cottage Service** when you need those capabilities. A disconnected service does not prevent ordinary local-file, office, or code work. Deploy and protect the service as a separate component, especially if it is reachable beyond your machine.
