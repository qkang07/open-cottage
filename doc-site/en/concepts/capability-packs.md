# Capability packs

Capability packs expose specialized tools only when a task needs them. The core file workflow is always available; enable Office, code, PDF, charts, image generation, research, tidy-up, or web automation deliberately in Settings.

Enabling a pack does not modify existing files. It changes the tool surface available to the Agent, so keep the selection narrow and review what the Agent proposes. External packs can be stored with a workspace when you choose to install them.
