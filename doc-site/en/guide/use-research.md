# Research

Enable **Deep research** when a report requires gathering and organizing evidence. State the question, intended reader, geography and date range, source constraints, and report structure before starting.

Connect Cottage Service when you need more reliable search or web fetching. Enable PDF handling for papers and charting for figures only when those are actually required. Keep citations, quotations, and uncertainty visible in the resulting report.

For questions with several subproblems, use [plan mode](./spec) to agree on the research questions and deliverable shape before collecting material.
