# Chat with the Agent

Use chat mode for questions, exploration, and contained changes. Explain the goal, output path, and non-negotiable boundaries. Add `@` references or attachments when the task depends on files in the workspace.

Read-only work can proceed directly. When the Agent needs to write files, inspect the tool card and resulting preview. Depending on your policy, changes can first enter staged review and sensitive operations wait for an explicit allow or reject decision.

When a task spans several files, public interfaces, or unclear requirements, switch to [plan mode](./spec) before execution.
