# Previews, references, and attachments

Open Cottage can preview common text and document outputs in the workspace, making it easier to inspect a result before it is accepted or shared. A preview is evidence for the file that exists in the current workspace; check it again after applying a staged change.

Type `@` in the composer to choose a file from the current workspace. The selected file becomes explicit context for the next request. Attachments provide additional task material, while the workspace remains the place for final files.

Use precise references and state what must not change. That gives the Agent a better boundary than a broad request such as “clean up this project.”
