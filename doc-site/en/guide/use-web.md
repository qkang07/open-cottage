# Web fetching and automation

Web screenshots, dynamic-page extraction, forms, and multi-step browser interactions require both **Web automation** and a connected [Cottage Service](/en/concepts/cottage-service-concepts). The service uses a local Chrome or Edge installation for those browser capabilities.

Before running an automated flow, state the target site, exact task, allowed actions, and desired output. Treat submissions, purchases, account changes, and data removal as sensitive actions that need clear approval.

Without Cottage Service, do not assume screenshots, dynamic extraction, or interactive webpage operations are available.
