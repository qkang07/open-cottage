# Documents, slides, and spreadsheets

Enable the **Office documents** capability when creating or editing Word documents, presentations, or spreadsheets. Put the source material in the workspace and state the intended output path, audience, format, and any files that must remain unchanged.

For a document, ask for a clear outline before a long draft when structure matters. For a presentation, decide the slide count and narrative first, then request one conclusion per slide. For a spreadsheet, specify the required sheets, formulas, input sources, and checks.

Preview the result in the workspace and inspect layout, density, alignment, formulas, and links before delivery. Use [plan mode](./spec) when the work has multiple inputs or approval stages.
