# The main interface

After a workspace opens, the file tree, conversation, and preview area work together. Use the file tree to inspect the folder, the conversation to state or refine a task, and the preview area to read generated content and changes without leaving the workspace.

The top bar opens **Settings** for models, capability packs, Cottage Service, and review policy. It also contains theme, language, and workspace controls. Configure those when needed; the usual path is to open a folder and start the first task first.

Use `@` in the composer to select a file from the current workspace. A file reference gives the Agent explicit context without copying its text by hand.
