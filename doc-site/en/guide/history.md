# Version History Beta

Version History is disabled by default and must be enabled for each workspace. It records version data under `.cottage/history/v2/` and lets you inspect differences and restore a file or an earlier workspace state.

Before restoring, verify the checkpoint and the files that will be affected. A restore action can replace current work, so use it deliberately and keep ordinary backups for important material.

Configure per-file and total workspace storage limits in Settings. When the limit is reached, make space or adjust the policy rather than assuming older work is safely retained elsewhere.
