## A small, local workflow

1. Open an existing folder.
2. Configure a model and the capabilities the task calls for.
3. State the goal, output path, and constraints in plain language.
4. Review the resulting files in the same workspace.

Open Cottage is a frontend application: your browser provides the interface and folder permission, while your local folder stays the source of truth. Connect optional Cottage Service only for enhanced search, dynamic web pages, screenshots, or browser automation.

Read [the five-minute setup](/en/guide/first-setup) to complete a first task, or explore [the core concepts](/en/concepts/).
