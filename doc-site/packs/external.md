# 安装外部能力

除了内置开关，还可以安装外部能力包。

## 操作步骤

1. 打开 **设置 → 能力配置 → 外部包**  
2. 选择安装示例包，或通过 URL 安装  
3. 回到「模型与能力」确认新能力是否出现并可开关  

![设置中的第三方能力导入与示例包入口](/images/external-pack-install.png)

高级用户也可把包放到工作区 `.cottage/packs/{id}/`。开发说明见 [编写 Capability Pack](/architecture/pack-authoring)。
也可以在设置里启用 **MCP** 服务器，把远程工具并入 Agent（默认关闭）。
