# 能力总览与开关

能力包决定 Agent「会哪些本事」。  
**基础能力始终可用**；办公、编码、PDF 等领域能力可在界面中查看和开关，实际状态以当前保存的配置为准。

## 怎么打开 / 关闭

1. 看向右侧聊天输入区上方的 **模型与能力**  
2. 打开本次任务需要的包  
3. 也可在 **设置 → 能力配置** 查看说明与工具列表  

![设置 → 能力配置 → 内置能力](/images/packs-toggle-panel.png)

系统可能根据你的话**建议**打开某包，但不会强行替你打开。
